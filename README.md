# Knownest 插件：练习（quiz-maker）

> 学习闭环（做题与复习）：内核级 9 工具（出题双写/补题/做题会话/复习调度/判分回流/学习统计/学习教练）+ 深度出题官 + 练习页。

Knownest 官方插件的**社区分发仓**（消费型样板）——本仓内容为主仓 plugins/quiz-maker/ 的同步快照，tag 与市场版本一致（当前 v0.42.0）。

## 安装（插件市场 · 社区通道）

- Knownest → 插件市场 → **社区**：搜索「练习」一键安装（GitHub topic `knownest-plugin` 自动收录）；
- 或在插件市场「更多安装方式」粘贴仓库地址：`https://github.com/bugjc/knownest-plugin-quiz-maker.git`。

## 仓库即样板

本仓即一份完整可运行的插件源：plugin.json（清单 + 权限 + i18n 词典）、index.js 入口、lib/ 实现（部分插件另带 golden-cases.json 黄金用例）。**Fork 本仓、改清单 id 与实现，即可发布你自己的 Knownest 插件。**
